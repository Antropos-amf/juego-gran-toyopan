# Los Mojones del Alférez Zamora

Juego en 3D sobre el paraje del Tibás (valle de Barva, siglo XVII) y la Gran Toyopán, ligado al proyecto [Historia de San Isidro de Heredia](https://historiadesanisidrodeheredia.com/).

**Jugar:** https://antropos-amf.github.io/juego-gran-toyopan/

Funciona en computadora (teclado y ratón) y en teléfono o tablet (controles táctiles). Necesita conexión a internet para cargar Three.js. El avance se guarda automáticamente en el navegador.
